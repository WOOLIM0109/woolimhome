# 슬라이드 밖에 내놓은 도형은 보류 사유가 아니다

## 무슨 일이 있었나

「240618 데브늄 사업제안서(파랑 ver.)」가 가림 편집에서 15장 중 12장 보류됐다.
화면에는 이렇게 떴다.

> 원본 검사에서 확정하지 못한 내용이 있어 이 장표는 보류됩니다.

원본을 직접 돌려 확인했다. 41장 중 **37장**이 같은 사유로 걸린다.

## 원인

이 파일은 디자이너가 **슬라이드 밖에 물건을 내놓고** 작업한 파일이다.

- 슬라이드 크기: `12192000 x 6858000`
- 글상자 묶음 하나: `off x=12384391` — 오른쪽 바깥
- 그림 둘: `x=12208734 y=-1770027`, `x=12499588 y=-786389` — 오른쪽·위쪽 바깥
- 또 한 묶음: `y=7513753 ~ 9585903` — 아래쪽 바깥

쓰다 남긴 것을 옆에 치워둔 것이고, 그 묶음이 37장에 그대로 복사돼 있다.

`lib/pc-worker/preparation/pptx-inspection.ts` 의 `normalizeRect` 는 도형을
슬라이드 안으로 자른다. 전부 바깥이면 남는 넓이가 없어 `null` 을 돌려준다.
`emit()` 은 그 `null` 을 **위치를 못 읽은 것**으로 보고 `GEOMETRY_UNRESOLVED` 를 붙인다.
이 경고는 `hasFatalRedactionWarning` 의 `/UNRESOLVED/` 에 걸려 장표를 보류시킨다.

**위치는 정확히 알고 있다.** 다만 화면 밖이라 PowerPoint 가 그림으로 내보낼 때
아예 그리지 않는다. 나오지 않는 것을 못 가린다고 막고 있는 셈이다.

위치를 **정말 모르는 경우**(도형에 `xfrm` 자체가 없고 상속으로도 못 찾는 경우)와
**알지만 화면 밖인 경우**를 지금은 똑같이 다룬다. 이 둘을 갈라야 한다.

## 고칠 것

### 1. `lib/pc-worker/preparation/pptx-inspection.ts` 의 `emit()`

지금:

```ts
const rect=input.rawRect?normalizeRect(input.rawRect):null;
if(!rect) warnings.add("GEOMETRY_UNRESOLVED");
primitives.push({ ... });
```

바꿀 것:

- `input.rawRect` 가 **있는데** `normalizeRect` 가 `null` 을 주면
  (= 위치를 알고, 슬라이드와 겹치는 넓이가 없다):
  `warnings.add("OFFSLIDE_SHAPES_NOT_RENDERED")` 를 남기고
  **그 도형은 `primitives` 에 넣지 않고 그대로 끝낸다.**
- `input.rawRect` 가 **없으면** 지금처럼 `GEOMETRY_UNRESOLVED` 를 붙이고
  `rect: null` 로 넣는다. 이쪽은 손대지 않는다.

도형을 빼는 이유: 화면에 그려지지 않으므로 가릴 것도, 검사할 것도 없다.
묶음(group) 안의 도형은 묶음 변환을 거친 **자기 자리**로 따지므로,
묶음이 밖에 있어도 자식이 화면 안으로 들어오면 그 자식은 그대로 남는다.
판단은 도형 하나하나로 한다.

### 2. `lib/pc-worker/preparation/local-review-server.ts`

`REDACTION_WARNING_LABELS` 에 한 줄 더한다.

```ts
OFFSLIDE_SHAPES_NOT_RENDERED: "슬라이드 밖에 놓인 도형이 있습니다. 그림에는 나오지 않아 가림 대상이 아닙니다.",
```

이 경고는 보류시키지 않는다. `hasFatalRedactionWarning` 의
`/TRUNCATED|INCOMPLETE|UNSUPPORTED|UNRESOLVED/` 에 걸리지 않는 이름이다.
그 판정 함수는 건드리지 않는다.

### 3. 시험

`lib/pc-worker/preparation/pptx-inspection.test.mjs` 에 더한다.

- 슬라이드 밖에 전부 나가 있는 도형은 `primitives` 에 나오지 않고
  `GEOMETRY_UNRESOLVED` 가 **붙지 않으며** `OFFSLIDE_SHAPES_NOT_RENDERED` 가 붙는다
- `xfrm` 이 없어 위치를 못 찾는 도형은 여전히 `GEOMETRY_UNRESOLVED` 가 붙고
  `rect: null` 로 남는다
- 일부만 걸친 도형은 지금처럼 잘려서 `rect` 가 나온다

## 건드리지 말 것

- `hasFatalRedactionWarning` 의 판정 목록과 지문 확인은 그대로 둔다.
  경고를 무르게 해서 여는 것이 아니라, 잘못 붙던 경고를 안 붙이는 것이다.
- `normalizeRect` 의 자르기 계산은 그대로 둔다.
- 런타임 꾸러미를 다시 만들거나 설치하지 않는다. 사무실 PC에서 따로 한다.
