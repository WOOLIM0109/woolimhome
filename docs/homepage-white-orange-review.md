# 울림 홈페이지 디자인 개편

작업일: 2026-09-21 · 브랜치: `design/white-orange-homepage`

## 디자인 기준

사용자가 제공한 기업 홈페이지 레퍼런스 6종을 기준으로 흰 배경, 검정 제목, 넓은 여백, 얇은 회색 구분선, 절제된 오렌지 포인트를 적용했다. KAON 레퍼런스의 여백과 제목, TK Chemical의 이미지와 텍스트 배치, 금융회사 레퍼런스의 정돈된 구획을 주요 기준으로 삼았다.

메인에서 승인한 줄바꿈은 유지하고, 회사소개·사업영역·포트폴리오·성공사례·인사이트·상담까지 같은 디자인 기준으로 정리했다. 서비스 제목의 불필요한 강제 줄바꿈은 제거했다.

- UI의 주황색은 사용자 지정 색상 `#EB6826` 하나로 통일했다. hover에도 같은 주황을 사용하며, 채워진 CTA의 글자와 화살표는 흰색이다.
- 기본 콘텐츠 컨테이너는 최대 1504px, 데스크톱 좌우 패딩 48px, 모바일 좌우 패딩 20px를 기준으로 정리했다. 메인 와이드 이미지는 별도 폭을 사용한다.
- 서비스 설명·목록·약력 등 본문은 17–18px, 모바일 본문은 16px로 확대하고 보조 정보도 읽기 쉽게 정리했다.
- 웹 제목과 본문은 로컬 Pretendard Variable로 통일했다. Paperlogy 웹 연결과 외부 Pretendard CSS 요청은 제거했다.

## 구현 범위

- `app/page.tsx`, `app/home.module.css`: 큰 제목 → 와이드 브랜드 이미지 → 사업영역 → 업무 방식 → 실제 포트폴리오 → 성과 → 고객사 → 전문성 → 후기·비교표 → 소식 → FAQ → 상담 순서로 메인을 재구성했다.
- 메인 업무 방식은 진단·기획·완성을 큰 가로형 흐름도로 보여주며, 모바일에서는 세로 흐름으로 전환한다.
- `Header`, `Footer`, `PageHero`: 공통 메뉴, 푸터, 하위 페이지 제목 영역을 정리했다. 푸터의 EXPLORE 메뉴는 제거하고 회사 슬로건·연락처·사업자정보·관리자 링크를 유지했다.
- `SectionHeader`, `ClientMarquee`, `FaqList`, `ContactBand`, `PublicSections.module.css`: 공개 페이지 공통 섹션을 평면적인 구성과 넓은 여백으로 통일했다.
- `ComparisonTable`: 비교표를 접지 않고 항상 표시한다. 주황색 울림컴퍼니 헤더와 강조된 울림 열을 적용하고, 모바일에서는 항목별로 울림컴퍼니와 일반 타사를 세로 배치한다.
- `data/home-testimonials.ts`: 기존 후기 6건을 문구 변경 없이 홈에서 분리했다.
- `app/layout.tsx`, `app/globals.css`: 공식 Pretendard Variable 1.3.9를 `next/font/local`로 제공하고 100–900 가변 굵기와 preload를 적용했다.
- `components/SiteMain.tsx`: 공개 페이지에 흰 배경·검정/중성 회색 토큰을 적용한다. 관리/파트너 페이지의 색상 토큰은 유지했다.
- 회사소개·대표 소개: 본인 사진을 제거하고 큰 인사말·브랜드 철학·약력 중심으로 재구성했다. 공개 페이지와 Person JSON-LD의 대표 사진 참조도 제거했다. 기존 사진 파일 자체는 삭제하지 않았다.
- 서비스 3종·RelatedServices: 읽기 쉬운 본문과 넓은 콘텐츠 폭, 새 서비스 이미지, 번호형 구성과 성과·과정을 적용했다.
- `CertificationFlow`: 기업인증 5개 분야를 병렬 선택지로 보여주고, 기업별 적용 검토를 거쳐 6개 혜택으로 이어지는 HTML/SVG 도식을 추가했다. 모든 인증을 순차적으로 취득해야 하는 구조로 표현하지 않으며, 기존 인증·혜택 설명과 적용 조건 안내를 유지했다.
- 포트폴리오 4종·성공사례 3종: 실제 이미지 중심 갤러리, 밑줄 필터, 넓은 사례 영역, 흰 상세 본문과 회색 성과 영역, 확대 창까지 정리했다.
- 뉴스·칼럼 목록과 상세: 선 중심 기사 목록과 읽기 편한 상세 본문으로 정리했다. 상세 컨테이너는 최대 1016px이며, 문장·표·FAQ·출처의 위계를 구분했다.
- 상담 페이지·ContactForm: 평면 입력창, 연락처 목록, 흰 글자·화살표가 있는 사각형 제출 버튼을 적용했다. 필드·필수 항목 검증·허니팟·제출 로직은 유지했다.
- 회사소개의 대표 소개 링크는 기존 `/about/ceo → /about` 리다이렉트를 유지하면서 페이지 내부 인사말 앵커로 연결했다.

페이지 metadata, canonical, 기존 JSON-LD 구조와 서비스·사례·후기·FAQ·고객사·연락처 데이터를 유지했다. 대표 사진 참조 제거 외에 회사 정보나 실적 수치를 변경하지 않았다. DB 데이터, 문의 접수 API, 자동화 처리 로직은 변경하지 않았다. 기존 이미지 생성 작업에 쓰는 Paperlogy TTF 파일은 유지하고 웹사이트 글꼴 연결만 제거했다.

글꼴 출처: [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard). 원본 SIL OFL 1.1 라이선스는 `public/fonts/Pretendard-LICENSE.txt`에 포함했다.

## 이미지

Built-in image_gen으로 제작한 기존 브랜드 이미지 2장에 신규 3장을 추가해 총 5장을 사용한다.

- `woolim-workspace-hero-v1`: 메인 와이드 작업공간 이미지.
- `woolim-editorial-detail-v1`: 메인 기획·편집 디자인 이미지.
- `woolim-document-studio-v2`: 비즈니스문서 서비스와 PPT 포트폴리오용 이미지.
- `woolim-brand-system-v2`: 디자인 서비스와 디자인 포트폴리오용 이미지.
- `woolim-strategy-studio-v2`: 사업계획서·IR 포트폴리오용 이미지.

신규 3장은 사용자 지정 `#EB6826`을 컬러 기준으로 제작한 실사 스타일 브랜드 콘셉트 이미지다. 실제 울림 사무실이나 고객 작업물의 현장 사진으로 표시하지 않는다. 실제 포트폴리오 영역에는 기존 승인된 고객 프로젝트 자료를 사용한다. 대표 인물 사진은 생성하지 않았다.

원본 PNG·웹용 WebP 파일과 최종 프롬프트: [homepage-brand-photography.md](homepage-brand-photography.md).

## 칼럼 복구

Git에서 제외된 로컬 환경변수 설정을 복구해 실제 공개 칼럼 19건을 다시 표시하도록 했다. DB 데이터는 변경하지 않았으며 환경변수 값이나 비밀정보는 커밋 대상에 포함하지 않는다.

`getPublishedColumnsResult`는 게시글과 조회 가능 상태를 함께 반환한다. 조회 오류·환경설정 문제와 정상 조회된 빈 목록을 화면에서 구분하며, 기존 `getPublishedColumns`의 배열 반환 계약과 공개 여부·게시 시각 필터·정렬은 유지한다. 실제 칼럼 목록과 실제 상세 페이지까지 시각 검증했다.

## 검증

- TypeScript 검사, ESLint, Next.js 프로덕션 빌드 통과.
- 프로덕션 HTML 19개 경로 모두 HTTP 200, canonical/JSON-LD 파싱 정상.
- 로컬 글꼴 HTTP 200, WOFF2 서명 정상. 로컬 Pretendard 사용과 가변 굵기 선언을 확인했다.
- CSS viewport 351px에서 공개 메뉴 16개 경로를 점검해 가로 넘침 0건과 Pretendard 적용을 확인했다.
- 390px 모바일에서 메인 업무 흐름도와 비교표의 세로 배치를 시각 확인했다.
- 320px에서 메인·회사소개·컨설팅·문서서비스·포트폴리오·입찰사례·상담·실제 칼럼 상세의 가로 넘침이 없음을 확인했다.
- 데스크톱에서 메인, 기업인증 도식, 사례 영역의 여백, 새 이미지, 칼럼 목록과 실제 칼럼 상세를 시각 확인했다.
- 디자인 인쇄·편집 필터 9개 결과, PPT 제안서 필터, 두 갤러리의 상세 창·다음 이미지·Escape 닫기, 입점·제휴 탭 3개 결과, 성과 내역 상세 열기·닫기를 확인했다.
- 상담 빈 폼 제출 시 이름 입력으로 포커스가 이동하고 필수 항목 검증이 동작하는 것을 확인했다. 실제 문의는 전송하지 않았다.
- 주황 CTA 및 SVG 화살표의 흰색 표시를 확인했다.
- 모바일 메뉴 열기, Escape 닫기와 포커스 복귀, 모바일 상담 페이지 이동을 확인했다.
- FAQ 접기·펼치기, 항상 표시되는 비교표, 데스크톱 Tab 이동 시 하위 메뉴 접근을 확인했다.
- 전체 `npm test` 984개 통과, 실패 0개. 첫 실행의 Windows 임시 폴더 권한 제한을 해소한 뒤 같은 전체 테스트를 다시 실행했다.

기존 middleware 파일명에 대한 Next.js deprecation 안내는 빌드에서 발생하며 이번 디자인 변경과는 별개다.

로컬 검토 주소: `http://127.0.0.1:3093` (`npm run start -- --hostname 127.0.0.1 --port 3093`). 공개 배포는 실행하지 않았다.
