# Gemini API 비용 보호 모드

## 기본 상태

- `GEMINI_ENABLED`는 값이 정확히 `true`일 때만 활성화됩니다.
- 미설정 및 `false`는 운영 환경을 포함해 모두 차단 상태입니다.
- 개발·미리보기 환경은 `GEMINI_ALLOW_NON_PRODUCTION=true`도 함께 설정하지 않으면 차단됩니다.
- API 키가 존재하는 것만으로는 호출할 수 없습니다.
- `PII_REDACTION_TERMS`가 비어 있으면 운영에서도 호출할 수 없습니다. 고객사·담당자·프로젝트 식별어를 먼저 등록해야 합니다.
- 현재 운영 환경은 사용자의 별도 승인 전까지 `GEMINI_ENABLED=false`를 유지합니다.

## 유일한 허용 경로

1. 관리자가 `/admin/editorial-maintenance`에서 원문과 수정본을 로컬 상태에 누적합니다.
2. `호출 내용 확인`을 눌러 대상 수, 입력량, 예상 토큰·비용, 캐시, 일·월 예산을 확인합니다. 이 단계는 Gemini를 호출하지 않습니다.
3. 확인 내용이 바뀌지 않은 상태에서 정확한 `AI 검수 실행` 버튼을 누릅니다.
4. 서버는 관리자, 일회용 확인 토큰, 콘텐츠 해시, 프롬프트 버전, 모델, 캐시, 예산, 전역 잠금을 다시 확인합니다.
5. 서버가 원문과 수정본의 차이를 계산하고 개인정보를 비식별화합니다.
6. 캐시 미적중일 때만 실제 변경 조각과 각 조각 주변의 짧은 문맥을 한 요청으로 전송합니다. 원문 전체와 변경 사이의 긴 미수정 구간은 전송하지 않습니다.

기존 원고 생성·재생성·일괄 재작성·파일 AI 분류·진단 API와 AI 크론은 보호 모드에서 네트워크 호출을 하지 않습니다.

## 상한과 재시도

- 기본 일일 호출 상한: 3회
- 기본 월간 호출 상한: 30회
- 기본 일일 비용 상한: USD 1
- 기본 월간 비용 상한: USD 10
- 사용자 작업 한 번은 변경 항목 전체를 한 개의 논리 요청으로 묶습니다.
- 전역 동시 호출은 1개입니다.
- 429 또는 5xx만 전송 재시도 1회가 허용됩니다.
- 호출·비용 상한은 최초 요청과 조건부 재시도까지 최대 2회분을 사전 예약하며, 원장에는 실제 네트워크 시도 수를 기록합니다.
- JSON 오류, 빈 응답, 타임아웃, 일반 오류는 자동 재시도하지 않습니다.
- 백그라운드·크론 재시도는 없습니다.

가격은 모델 변경에 대비해 환경변수로 관리하며, 기본값은 실제 비용을 낮게 잡지 않도록 보수적으로 계산합니다.

## 캐시와 기록

- 캐시 키: `SHA-256(contentHash + promptVersion + model)`
- `contentHash`는 개인정보 필터 후의 실제 변경 조각을 canonical 정렬해 계산하므로 임시 화면 ID나 입력 순서가 바뀌어도 동일합니다.
- 동일 입력은 저장된 결과를 반환하며 네트워크를 호출하지 않습니다.
- 서버 전용 `content_automation_runs`에 승인, 전역 임대, 캐시, 호출 원장을 분리해 기록합니다.
- 호출 기록에는 프로젝트, 환경, 관리자, 모델, 프롬프트 버전, 콘텐츠 수, 입력·출력·전체·캐시 토큰, 캐시 적중 여부, 각 네트워크 시도의 상태, 예상·실제 비용이 포함됩니다.

`.codex-tmp/`와 로컬 환경 파일은 Git 및 Vercel 업로드 대상에서 제외합니다. 과거 로컬 진단 스크립트가 배포 보호장치를 우회해 포함되지 않도록 하기 위한 조치입니다.

## 운영 활성화 체크리스트

사용자가 운영 호출을 명시적으로 승인한 뒤에만 다음을 진행합니다.

1. 공식 모델 가격을 확인하고 토큰 단가 환경변수를 갱신합니다.
2. 일·월 호출 및 비용 상한을 확인합니다.
3. `PII_REDACTION_TERMS`에 현재 고객사·담당자·프로젝트·회사 식별어를 등록합니다. 비어 있으면 서버가 호출을 차단합니다.
4. `GEMINI_ENABLED=true`를 운영 환경에만 설정합니다.
5. 배포 후 `호출 내용 확인` 화면에서 활성 상태와 예산을 확인합니다.
6. 실제 호출은 관리자가 `AI 검수 실행`을 직접 눌렀을 때만 수행합니다.

## 테스트 원칙

구현 및 회귀 테스트에서는 운영 Gemini API를 호출하지 않습니다. 네트워크 동작은 stubbed `fetch`로만 검증합니다.
