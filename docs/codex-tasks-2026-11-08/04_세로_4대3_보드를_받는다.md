# 세로 4:3 장표를 포트폴리오로 쓸 수 있게 한다

과업 문서: `docs/과업-포트폴리오-세로-4대3-보드.md`

## 지금 무엇이 막는가

세로 4:3(19.05 × 25.4cm, 비율 **0.75**)은 변환에서 거절된다.

```
NON_PRESENTATION_LAYOUT: Slide ratio 0.75 is not 16:9, 4:3, A4 landscape, or A4 portrait.
```

A4 세로는 0.707 이라 6% 차이가 나고, 허용 오차 안에 들어오지 않는다.
회사소개서·제안서에서 흔한 규격이므로 한 건으로 끝날 문제가 아니다.

## 어떻게 만드는가

**새로 그리지 않는다.** A4 세로 보드를 그대로 가져와 비율만 바꾼다.

`lib/portfolio/approved-a4-portrait-templates.ts` 는 카드 자리를
**가운데 점**으로 잡고 높이는 `width * (1 / 비율)` 로 계산한다.
비율만 0.707 → 0.75 로 바꾸면 카드 위치·각도·그림자·로고·제목칸은 그대로 있고
카드만 6% 짧아진다. 구성이 흐트러지지 않는다.

## 고칠 것

### 1. 새 보드 파일

`lib/portfolio/approved-portrait-4x3-templates.ts` 를
`approved-a4-portrait-templates.ts` 에서 복사해 만든다.

바꾸는 것은 이것뿐이다.

- `APPROVED_PORTRAIT_4X3_SLIDE_ASPECT_RATIO = 3 / 4`
- 버전 `approved-portrait-4x3-v1`, 묶음 `approved-portrait-4x3-suite`
- 장표 이름 `portrait-4x3-thumbnail-1`, `portrait-4x3-body-1-flatlay`,
  `portrait-4x3-body-2-triptych`, `portrait-4x3-body-3-grid`,
  `portrait-4x3-body-4-studio` (대표 1장 + 본문 4장, A4 세로와 같은 구성)

**그 밖의 숫자는 한 자리도 바꾸지 않는다.** 화면 크기, 카드 가운데 점,
카드 너비, 기울기, 그림자, 로고 자리, 제목칸, 배치 순서 전부 그대로다.

배경은 A4 세로가 쓰는 것을 **그대로 쓴다.** 새 그림을 만들지 않는다.
등록이 필요하면 같은 정의를 가리키게만 한다.

### 2. 묶음 등록

`lib/portfolio/approved-mockup-suites.ts` 에 새 규격을 더한다.

- `ApprovedMockupSuiteAspectClass` 에 `"4:3_portrait"` 추가
- `APPROVED_PORTRAIT_4X3_SUITE` 를 만들어 `APPROVED_MOCKUP_SUITES` 에 넣는다
- `getApprovedMockupSuite` 의 옛 통로(`16:9`, `a4_landscape` 만 받는 곳)는
  **건드리지 않는다.** `a4_portrait` 가 지나는 길을 그대로 따른다

### 3. 받는 비율 목록

- `lib/pc-worker/preparation/pptx-inspection.ts` 의 `classifyPreparationPageSize`
  표에 `["4:3_portrait", 3 / 4, "standard_4_3_portrait"]` 를 더하고,
  `PreparationAspect` 와 `PreparationPageSizeVariant` 에도 더한다
- `tools/woolim-pc-worker/worker.ps1` 의 `Test-SupportedPageRatio` 에
  `(3.0 / 4.0)` 을 더하고, 거절 문구에도 세로 4:3 을 적는다
- 같은 파일의 `$WorkerVersion` 을 `2.11.0` 으로 올린다

### 4. 나머지 자리

`a4_portrait` 가 나오는 **모든 자리에서 `"4:3_portrait"` 도 같이 다룬다.**
지금 아래 파일들이 그 규격을 알고 있다.

```
lib/pc-worker/preparation/preparation-review-service.ts
lib/pc-worker/preparation/source-format-choice.ts
lib/portfolio/approved-assigned-board-renderer.ts
lib/portfolio/job-runner.ts
lib/portfolio/mockup-route.ts
lib/portfolio/short-mockup.ts
lib/portfolio/slide-selection.ts
lib/portfolio/thumbnail-title-overlay.ts
components/admin/WorkQueue.tsx
```

각 자리에서 `a4_portrait` 가 세로로 다뤄지는 방식을 그대로 따른다.
화면에 보이는 한국어 이름은 「세로 4:3」으로 적는다.

### 5. 시험

보드 등록·규격 분류·화면 표시에 회귀 시험을 더한다. 특히 이 둘을 꼭 넣는다.

- 비율 0.75 장표가 `4:3_portrait` 로 분류되고 더 이상 `NON_PRESENTATION_LAYOUT` 이 아니다
- 새 보드의 카드 높이가 `너비 × 4 / 3` 이고, 가운데 점·기울기·그림자는
  A4 세로 보드와 **같은 값**이다

## 건드리지 말 것

- **`lib/portfolio/a4-source-fit.ts` 의 3% 한도는 그대로 둔다.**
  원본과 다른 모양으로 나가는 것을 막는 장치다. 전용 보드를 만드는 것이
  이 과업의 방법이고, 그 숫자를 무르게 해서 여는 것이 아니다.
- A4 세로 보드의 숫자와 버전은 그대로 둔다. 새 파일에만 손댄다.
- 지문 확인, `hasFatalRedactionWarning` 의 판정 목록은 그대로 둔다.
- `PREPARATION_RULE_VERSION` 은 올리지 않는다. 이미 받아들인 장표의
  분류 결과가 달라지지 않는다.
- 런타임 꾸러미를 다시 만들거나 설치하지 않는다. 사무실 PC에서 따로 한다.

```
npm run verify
```
