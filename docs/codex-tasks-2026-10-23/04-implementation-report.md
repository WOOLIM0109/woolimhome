운영 초안의 현재 상태·최신 PC 변환 충족 여부·확정 이미지 세트 행·Vercel 실제 시간은 확인하지 않았다. 운영 버튼은 누르지 않았다. 화면 증빙은 실제 컴포넌트의 로컬 합성 시험이므로 운영 인증과 서버 연결은 배포 후 확인 대상이다.

대표님이 병합·배포를 확인한 다음, 04 문서 4절 순서로 진행한다.

1. `/admin/reviews`에서 해당 「경영컨설팅 제안서 디자인: 방대한 성과 지표와…」 검수 필요 카드를 찾는다.
2. 카드 제목 바로 아래 **「이미지만 다시 만들기 · 글은 그대로」**를 누른다. 펼칠 필요는 없다.
3. `목업 이미지를 새 가림 규칙으로 다시 만들었습니다.`면 다음으로 간다. `원본 PPT를 다시 변환해야 해서 PC 워커에 작업을 넘겼습니다…`면 PC를 켜 두고 10~30분 뒤 같은 버튼을 다시 누른다. 변환/재제작 진행 중 문구면 기다린 뒤 새로고침한다.
